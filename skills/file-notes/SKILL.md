# 文件注释与备份说明规范

## 为什么需要这个 skill

AI 生成的文件、做的备份，**当时清楚，事后糊涂**。隔一段时间（或换一个对话/AI）再看，就不知道：
- 这个备份是备份什么、为什么删的、能不能恢复？
- 这个脚本是干什么的、怎么跑、依赖什么？
- 这个数据文件是什么格式、从哪来的、字段什么意思？

**本 skill 的目标：让 AI 产出的文件和备份「自带说明书」**，事后任何人（包括未来的 AI）打开就能懂，不用重新考古。

## 核心规则

### 规则一：备份必须附带说明文件

**任何"先备份、后删除/移动"的操作**，都必须在备份目录里放一个说明文件（通常 `README.md`），记录清楚：

- **这是什么**（被备份的文件/目录是什么）
- **原位置**（原来在哪）
- **为什么**（为什么备份/为什么删除）
- **时间**（什么时候做的）
- **怎么恢复**（怎么放回去）

**为什么**：备份如果没有说明，过一阵就变成"看不懂的垃圾"，既不敢删也不敢用，等于没备份。

**模板**（按实际情况调整，不必逐字套）：

```markdown
# <备份目录名> 说明

> 备份时间：<YYYY-MM-DD>
> 备份原因：<一句话>

## 备份清单

### 1. `<目录/文件名>`
- 原位置：`<原路径>`
- 内容：<这是什么>
- 备份/删除原因：<为什么>
- 恢复方法：<怎么放回去>

## 如何恢复

<一行命令或步骤>
```

> 若备份目录里东西多，用上面的"清单"逐条列；若只有一个，简短说明即可。

### 规则二：产出的文件必须能看懂

**创建任何"以后可能需要理解"的文件时**，要让它自带解释。判断标准很简单：

> **"如果三个月后我（或别的 AI）打开这个文件，能不能立刻知道它是干什么的？"**
> 不能 → 就要加说明。

不同文件类型的做法：

| 文件类型 | 怎么加说明 |
|---------|-----------|
| **脚本**（.ps1/.sh/.py/.bat）| 文件头写注释块：用途、怎么运行、参数、依赖、注意事项 |
| **配置文件**（.json/.yaml/.ini）| 关键字段加注释（若格式支持），或在同目录放 `README.md` 解释 |
| **数据/输出文件**（.csv/.txt/.json）| 同目录放说明，或用首行注释写明：来源、字段含义、生成方式 |
| **目录/文件夹** | 里面放 `README.md` 说明用途和内容 |
| **临时/中间文件** | 文件名前缀 `tmp_` / `_` 标明，或放临时目录，不必详注 |

**脚本头部注释模板**：

```
# =====================================================================
#  <脚本名> — <一句话用途>
#  用法：<怎么运行>
#  参数：<有哪些参数>
#  依赖：<需要什么>
#  说明：<注意事项/坑>
# =====================================================================
```

### 规则三：什么时候可以不加

避免过度注释造成噪音。以下情况**可以不加或极简**：

- **临时中间文件**（用完即弃）——但建议名字能自解释（如 `tmp_download.log`）
- **用户明确说不要注释**
- **内容自解释**（比如一个叫 `2026-09-09_会议记录.md` 的文件，本身就是说明）
- **标准约定文件**（如 `.gitignore`、`LICENSE`）

判断的度：**"加了有明显帮助"就加，"加了纯属废话"就不加。**

## 执行流程

1. **识别操作类型**：这次是"备份/删除"还是"产出文件"？
2. **备份类** → 先备份，再在备份目录写 `README.md` 说明（规则一）。
3. **产出类** → 判断"以后看不看得懂"，看不懂就加注释/说明（规则二）。
4. **自检**：做完后问自己——"三个月后打开，我能懂吗？" 不能就补上。

## 注意事项

- **备份和说明要一起做**，别只备份不写说明（那就白备份了）。
- **说明要写"为什么"**，不只是"是什么"——原因往往比内容更重要（比如"因为源仓库失效所以删除"）。
- **路径写全**，方便以后直接复制粘贴恢复。
- **中文/英文都行**，跟用户的语言习惯一致。

## 给模型的提醒

本 skill 是"让产出物可被理解"的**习惯规范**，不是要求你给每个文件写长篇大论。核心就一句话：**备份要带说明，产出要能看懂；有用于事，无用于省。**
